# Robotics Engineering Portfolio

안녕하세요. 대구가톨릭대학교 로봇공학과에서 로봇 제어, 임베디드 시스템, 인공지능 기술을 공부하고 있는 박민상입니다.

하드웨어와 소프트웨어를 연계한 시스템 개발에 관심이 있으며, 다양한 프로젝트를 통해 로봇 제어 및 프로그래밍 경험을 쌓고 있습니다.

## Tech Stack

**Programming**
- C / C++
- Python

**Hardware & Embedded**
- Arduino Mega 2560
- ATmega128
- ESP32
- Jetson Orin Nano

**Robotics & AI**
- ROS2
- YOLOv8
- OpenCV
- ONNX Runtime

**Communication**
- LoRa
- UART, I2C
- Wi-Fi

## Projects

### 01. Embedded System
**ATmega128 기반 임베디드 시스템 실습**

타이머와 인터럽트를 활용한 LED 제어, 시간 측정, FND 및 8×8 Dot Matrix 제어 실습

[프로젝트 자세히 보기](01_Embedded-System/)

### 02. Maze Passing Robot
**Arduino 기반 미로통과 자율주행 로봇**

초음파 센서 5개를 활용한 장애물 회피 및 중앙 정렬, RC 수동조종과 PWM 기반 모터 제어 구현

[프로젝트 자세히 보기](02_Maze-Robot/)

### 03. AI Waste Classification
**딥러닝 기반 실시간 쓰레기 분류 시스템**

YOLOv8과 ConvNeXt Tiny를 활용한 객체 탐지 및 쓰레기 분류, ONNX 기반 실시간 영상 처리 구현

[프로젝트 자세히 보기](03_AI-Waste-Classification/)

### 04. ROS2 Bootcamp
**ROS2 기반 로봇 시스템 개발 팀 프로젝트**

ROS2 부트캠프에 참여하여 로봇 시스템 개발과 팀 협업을 경험한 프로젝트

[프로젝트 자세히 보기](04_ROS2-Bootcamp/)

### 05. Smart Farm IoT System
**ESP32 & LoRa 기반 스마트팜 환경 모니터링 및 제어 시스템**

ESP32와 LoRa 무선 통신을 활용한 7종 환경 센서 데이터 수집, 다중 구역 모니터링 및 펌프·팬 제어 시스템 개발

- 개발 기간: 2026.09 ~ 2026.11.17
- 진행 상태: 개발 진행 중
- 프로젝트 형태: 팀 프로젝트

[프로젝트 자세히 보기](05_Smart-Farm-IoT/)

## About This Portfolio

본 포트폴리오는 대학 전공 수업, 팀 프로젝트 및 부트캠프 활동을 통해 진행한 프로젝트를 정리한 공간입니다.

각 프로젝트 폴더에서 개발 환경, 주요 구현 기능, 소스코드 및 관련 보고서를 확인할 수 있습니다.
