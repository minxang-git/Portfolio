# Embedded System

## Project Introduction
ATmega128을 활용한 임베디드 시스템 제어 실습 프로젝트입니다.

## Main Features
- Timer0 및 Interrupt를 활용한 시간 제어
- LED 점등 및 소등 제어
- 밀리초 단위 시간 측정
- FND를 활용한 숫자 표시
- 버튼 입력을 통한 제어

## Development Environment
- MCU: ATmega128
- Language: C
- IDE: Microchip Studio

## Source Code
| File | Description |
|---|---|
| led_timer.c | 타이머 인터럽트를 활용한 LED 제어 |
| time_measurement.c | 밀리초 단위 시간 측정 및 LED 제어 |
| fnd_display.c | FND 숫자 표시 및 버튼 입력 처리 |

## Learning Points
타이머와 인터럽트를 활용한 시간 관리, 마이크로컨트롤러의 입출력 제어 및 FND 출력 방식을 학습했습니다.
