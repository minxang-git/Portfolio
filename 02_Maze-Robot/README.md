# Maze Passing Robot

## 프로젝트 개요
Arduino Mega 2560과 초음파 센서 5개를 활용하여 장애물을 감지하고 회피하는 미로통과 로봇 프로젝트입니다.

자율주행 및 RC 수동조종 모드를 구현하고, PWM 기반 모터 속도 제어와 중앙 정렬 기능을 적용하였습니다.

## 개발 환경
- Language: C++
- Board: Arduino Mega 2560
- IDE: Arduino IDE
- Hardware: HC-SR04, L298N, DC Motor, RC Receiver

## 주요 기능
- 초음파 센서 5개를 활용한 장애물 감지 및 회피
- 좌우 벽과의 거리 비교를 통한 중앙 정렬
- RC 조종기를 이용한 수동 주행
- 버튼을 통한 자율주행 / RC 모드 전환
- PWM 기반 모터 속도 제어
- 가감속 및 차동 회전 제어
