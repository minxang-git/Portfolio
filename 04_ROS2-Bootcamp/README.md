# ROS2 Bootcamp Project

## 프로젝트 개요
ROS2 기반 로봇 시스템 개발 부트캠프에서 진행한 팀 프로젝트입니다.

ROS2를 활용한 로봇 제어 및 시스템 구성 과정을 학습하고, 팀원들과 함께 프로젝트를 수행하였습니다.

## 개발 환경
- Framework: ROS2
- Language: Python
- OS: Ubuntu

## 주요 활동
- ROS2 기반 로봇 제어 시스템 개발
- ROS2 노드 및 토픽 통신 구조 학습
- 로봇 시스템 구성 및 동작 테스트
- 팀 프로젝트 개발 및 결과 정리

## 프로젝트를 통해 배운 점
ROS2 환경에서 로봇 소프트웨어를 구성하고 팀원들과 협업하는 과정을 경험하였습니다. 또한 로봇 시스템 개발에 필요한 코드 관리와 프로젝트 문서화의 중요성을 배울 수 있었습니다.
