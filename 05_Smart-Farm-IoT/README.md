# Smart Farm IoT System

## 프로젝트 개요
ESP32와 LoRa 무선 통신을 활용하여 스마트팜 환경을 원격으로 모니터링하고 제어하는 **팀 프로젝트**입니다.

7종의 환경 센서 데이터를 수집하여 LoRa 통신으로 전송하고, 웹 대시보드를 통한 실시간 모니터링과 수중 펌프 및 환기 팬의 자동/수동 제어 시스템을 개발하고 있습니다.

- **개발 기간:** 2026.09 ~ 2026.11.17
- **진행 상태:** 개발 진행 중
- **프로젝트 형태:** 팀 프로젝트

## 개발 환경
- Language: C/C++
- Board: ESP32
- IDE: Arduino IDE
- Communication: LoRa, UART, I2C, Wi-Fi
- Hardware: 환경 센서 7종, 릴레이, 수중 펌프, DC 팬

## 주요 기능
- 7종 환경 센서 데이터 수집
- LoRa 기반 장거리 무선 데이터 송수신
- 다중 구역 환경 데이터 모니터링
- 릴레이를 활용한 펌프 및 팬 제어
- 웹 대시보드 기반 실시간 모니터링 및 제어
