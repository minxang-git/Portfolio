# Robotics Engineering Portfolio

대구가톨릭대학교 로봇공학과 박민상입니다.

로봇 제어, 임베디드 시스템, AI 분야에 관심이 있으며 하드웨어와 소프트웨어를 연계한 프로젝트를 진행하고 있습니다.

## Tech Stack

- **Languages:** C/C++, Python
- **Embedded:** Arduino, ATmega128, ESP32, Jetson Orin Nano
- **Robotics & AI:** ROS2, YOLOv8, OpenCV, ONNX Runtime
- **Communication:** LoRa, UART, I2C, Wi-Fi

## Projects

### 01. [Embedded System](01_Embedded-System/)
ATmega128 기반 타이머, 인터럽트, LED, FND 및 Dot Matrix 제어 실습

### 02. [Maze Passing Robot](02_Maze-Robot/)
Arduino 기반 장애물 회피 자율주행 로봇 및 RC 수동제어 구현

### 03. [AI Waste Classification](03_AI-Waste-Classification/)
YOLOv8과 ConvNeXt Tiny를 활용한 실시간 쓰레기 탐지 및 분류

### 04. [ROS2 Bootcamp](04_ROS2-Bootcamp/)
ROS2 기반 로봇 시스템 개발 및 팀 프로젝트

### 05. [Smart Farm IoT System](05_Smart-Farm-IoT/)
ESP32와 LoRa 기반 다채널 환경 모니터링 및 제어 시스템 (진행 중)
