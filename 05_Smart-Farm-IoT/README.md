# Smart Farm IoT System

## 프로젝트 개요
ESP32와 LoRa 무선 통신 기술을 활용한 **스마트팜 환경 모니터링 및 제어 시스템** 개발 프로젝트입니다.

다양한 환경 센서 데이터를 수집하고, 무선 통신을 통해 원격으로 모니터링하며 수중 펌프와 환기 팬 등을 제어하는 시스템을 개발하고 있습니다.

- **개발 기간:** 2026.09 ~ 2026.11.17
- **진행 상태:** 개발 진행 중

## 개발 환경
- Language: C/C++
- Board: ESP32
- IDE: Arduino IDE
- Communication: LoRa, UART, I2C, Wi-Fi
- Hardware: 환경 센서, 릴레이, 수중 펌프, DC 팬

## 주요 기능
- 7종 환경 센서 데이터 수집
- LoRa 기반 무선 데이터 송수신
- 다중 구역 환경 데이터 모니터링
- 릴레이 기반 펌프 및 팬 제어
- 웹 기반 환경 데이터 확인 및 제어
