# Smart Farm IoT System — Technical Details

## 1. 시스템 개요

ESP32와 LoRa(E32-900T20D, 915MHz)를 기반으로 다수의 환경 센서를 연결하고, 센서 데이터를 원격으로 전송하는 스마트팜 IoT 시스템입니다.

송신기(Tx)는 센서 데이터 수집과 액추에이터 제어를 담당하며, 수신기(Rx)는 데이터를 수신하여 웹 대시보드를 통해 확인할 수 있도록 구성하는 것을 목표로 합니다.

## 2. 시스템 구성

**송신기(Tx)**
- ESP32 DevKitC WROOM-32D
- LoRa E32-900T20D
- 환경 센서 7종
- 수중 펌프 2개
- DC 팬 2개
- 릴레이 모듈 4개

**수신기(Rx)**
- ESP32
- LoRa E32-900T20D
- Wi-Fi 웹서버

**데이터 흐름**

환경 센서 → ESP32(Tx) → LoRa 통신 → ESP32(Rx) → 웹 대시보드

## 3. 환경 센서 구성

| 측정 항목 | 사용 센서 | 통신 방식 |
|---|---|---|
| CO2 | MH-Z19C | UART |
| 온습도 | AM2302 / DHT22 | Digital |
| 토양 수분 | SEN0193 | ADC |
| 조도 | BH1750 | I2C |
| 수온 | DS18B20 | OneWire |
| 수질(TDS) | SZH-TSM002 | ADC |
| 수위 | SEN0204 | Digital |

## 4. 송신기(Tx) GPIO 구성

| 구성 요소 | ESP32 GPIO |
|---|---|
| LoRa RX / TX | 4 / 5 |
| CO2 RX / TX | 16 / 17 |
| 온습도 센서 | 13 |
| 수온 센서 | 14 |
| 조도 SDA / SCL | 21 / 22 |
| 토양 수분 센서 | 32 |
| 수질(TDS) 센서 | 33 |
| 수위 센서 | 34 |
| 관수 펌프 릴레이 | 25 |
| 양액 펌프 릴레이 | 26 |
| 환기 팬 릴레이 | 27 |
| 순환 팬 릴레이 | 12 |

## 5. 수신기(Rx) GPIO 구성

| 구성 요소 | ESP32 GPIO |
|---|---|
| LoRa RX | 16 |
| LoRa TX | 17 |
| 전원 | USB 5V |

## 6. LoRa 무선 통신

- 사용 모듈: E32-900T20D
- 주파수: 915MHz
- 통신 인터페이스: UART
- 송신기별 채널 또는 ID를 구분하는 다채널 통신 구조
- 복수 구역의 환경 데이터를 하나의 수신기에서 통합 관리하는 구조

장거리 통신 성능과 다중 송신기 연결 안정성은 실제 환경에서 검증할 예정입니다.

## 7. 액추에이터 제어

릴레이 모듈을 활용하여 다음 장치를 제어하도록 구성합니다.

- 관수용 수중 펌프
- 양액 공급용 수중 펌프
- 온실 환기 팬
- 공기 순환 팬

센서 데이터에 따른 자동 제어와 웹 대시보드를 통한 수동 제어를 목표로 합니다.

## 8. 전원 구성

**메인 전원**
- Mean Well 5V 7A SMPS

**비상 전원 설계**
- TP4056 충전 모듈
- 18650 리튬이온 배터리
- DC-DC Boost Converter

비상 전원 구성은 전원 전환 회로의 안전성과 실제 동작 검증이 필요한 설계 항목입니다.

## 9. 향후 개발 및 검증 항목

- 센서 데이터 수집 및 정확도 확인
- LoRa 통신 거리와 장애물 환경별 수신 안정성 측정
- 다중 송신기 데이터 구분 및 통합 수신 테스트
- 릴레이 기반 자동/수동 제어 동작 검증
- 웹 대시보드 기능 테스트
- 전원 공급 및 비상 전원 전환 안정성 확인
