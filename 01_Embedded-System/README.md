# Embedded System

## Project Introduction

ATmega128 마이크로컨트롤러를 활용하여 타이머, 인터럽트 및 입출력 장치를 제어하는 임베디드 시스템 실습 프로젝트입니다.

## Main Features

- Timer0를 활용한 시간 제어
- Interrupt를 이용한 주기적인 이벤트 처리
- LED 점등 및 소등 제어
- FND를 활용한 숫자 표시
- 버튼 입력 상태 감지

## Development Environment

- MCU: ATmega128
- Language: C
- IDE: Microchip Studio

## Learning Points

타이머와 인터럽트를 활용한 시간 관리 및 마이크로컨트롤러의 입출력 제어 방법을 학습했습니다.
